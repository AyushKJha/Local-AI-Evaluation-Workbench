# Local AI Evaluation Workbench

A single-owner application for developers to compare local AI models on quality, latency and cost using SQLite.

Node.js 24+, SQLite, server-side validation, idempotent CRUD requests, reviewed browser interface. Database is excluded from GitHub. Owner app data stays on the worker.

- Import evaluation dataset via CSV/JSON
- Run model comparisons against locally hosted agents
- Generate comparison reports with metrics
