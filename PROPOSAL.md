# Local AI evaluation workbench

Developers need repeatable comparisons of model quality, latency and cost.

## Project direction
Create new project · Problem-derived idea

Originality is unverified; review the existing-solution check before claiming novelty.

## Target users
Developers building AI applications

## MVP
- Import a small evaluation dataset
- Run comparisons against local models
- Compare quality and latency in a report

## Suggested stack
Node.js, TypeScript, local AI; choose storage after validating the workflow.

## Critic
Source interest does not prove unmet demand. Interview target users and compare existing products before committing.
